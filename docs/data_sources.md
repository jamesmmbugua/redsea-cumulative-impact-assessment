# Data sources

Starting list. Record the actual file, date and licence for each layer in
`config/data_catalogue.csv`.

## Boundaries and base layers

| Data | Source |
|---|---|
| EEZ boundary | Marine Regions (VLIZ), World EEZ dataset |
| Coastline | OpenStreetMap coastline, or GSHHG |
| Bathymetry | GEBCO global grid |
| Protected areas | WDPA (Protected Planet), national NCW data |

## Ecosystem components

| Data | Source |
|---|---|
| Coral reefs, geomorphic and benthic zones | Allen Coral Atlas |
| Mangroves | Global Mangrove Watch |
| Seagrass | UNEP-WCMC global seagrass, national surveys |
| Saltmarsh and tidal flats | UNEP-WCMC, Murray et al. global tidal flats |
| Species occurrences | OBIS, GBIF |
| Dugong, turtles, whale sharks | Published surveys (KAUST, PERSGA, national), tagging studies |
| Seabirds | BirdLife International (IBAs), literature |
| Productivity | Bio-ORACLE chlorophyll and primary productivity, Copernicus Marine |
| Coral reef condition | Project coral survey sites (100) |

## Pressures

| Data | Source |
|---|---|
| Shipping density | AIS data (commercial providers, EMODnet-style density, or national) |
| Commercial fishing | Global Fishing Watch |
| Desalination plants | National authorities (SWPC, WTTCO), literature inventories |
| Ports and coastal infrastructure | OpenStreetMap, national port authorities, imagery |
| Planned developments | Developer and government planning documents |
| Coastal population | WorldPop |
| Night lights | VIIRS (NASA Black Marble or EOG annual) |
| Wastewater outfalls | National water and environment agencies |
| Aquaculture | National aquaculture records, imagery |
| Dive sites and resorts | Tourism authorities, OSM, dive operator listings |

## Climate

| Data | Source |
|---|---|
| Temperature, pH, oxygen, salinity (present and SSP1-2.6, SSP2-4.5, SSP5-8.5) | Bio-ORACLE v3 (ERDDAP server) |
| Marine heatwaves, Degree Heating Weeks | NOAA Coral Reef Watch |
